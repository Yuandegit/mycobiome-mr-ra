## 方法

### 【新增小节：跨族群可迁移性】

由于目前尚无日本人群肠道真菌组全基因组关联研究，无法在结局人群中对暴露效应进行直接重复。我们因此通过工具等位基因频率的一致性来间接评估跨族群可迁移性，该指标决定了所选工具在结局样本中是否仍保持多态并具有信息量。在协调阶段，等位基因频率已对齐至同一效应等位基因。对每个有效工具，我们比较汉族暴露 GWAS 与日本生物银行结局 GWAS 报告的等位基因频率，分别在原始尺度与 logit 尺度上计算 Pearson 与 Spearman 相关，并汇总绝对频率差。我们分别评估全部工具与低频子集（暴露次要等位基因频率低于 0.05），并核实没有工具在日本样本中变为单态。频率一致性用于支持工具的可迁移性，而非证明暴露效应量在人群间完全相同。

### 【新增小节：第一阶段校准与赢家诅咒】

工具选择与工具强度估计使用了同一批暴露关联，因此样本内解释方差与 F 统计量均存在第一阶段选择偏倚（赢家诅咒）。由于无法获得交叉验证所需的个体水平与分队列数据，我们采用两种统计校准，并将原始值报告为乐观上界。经验贝叶斯校准假设真实非中心参数服从方差为 τ² 的正态先验；τ² 在考虑双侧选择阈值的前提下，由所选统计量的边际分布以最大似然估计，每个统计量按因子 τ²/(τ² + 1) 收缩。第二种校准采用双侧截断条件最大似然估计，在统计量超过选择阈值的条件下最大化非中心参数的似然。对每个特征，我们报告原始、经验贝叶斯与条件 MLE 三种口径下的总 R²，以及相应的联合 F 统计量 F = [R²/(1 − R²)] × [(n − 1 − k)/k]，其中 k 为工具数。由于工具已按 r² < 0.001 剪枝、近似独立，故以联合 F 替代个体数据的条件 F。

### 【新增小节：多效性稳健估计量】

除逆方差加权、加权中位数、MR-Egger 与稳健调整轮廓评分法外，我们另采用四种估计量。加权众数法识别各变异 Wald 比的逆方差加权分布之众数，标准误由 bootstrap 获得。污染混合法将各变异 Wald 比建模为以共同因果效应为中心的有效正态分量与横跨候选范围的均匀无效分量的混合，对混合比例进行轮廓估计并给出基于似然的 95% 区间。MR-Lasso 在设计矩阵 [bx, Iₙ] 上对各变异截距施加 L1 惩罚；鉴于饱和设计在小样本下使交叉验证与 BIC 选择不稳定，我们沿精确的最小角回归路径求解 Lasso，并在因果项进入的确定性步骤处评估，将此时截距非零的变异标记为多效。加权总体最小二乘估计量允许暴露与结局关联同时存在不确定性，且不剔除变异。最后，我们报告学生化残差阈值在 2.5、3.0、3.5、4.0 变化时的单遍逆方差加权估计，使阈值依赖显式化，而非仅选取单一截断值。

## 结果

### 【插入主逆方差分析之后：多效性稳健估计】

在 115 个属级特征中，污染混合法未返回任何名义显著关联，这是面板内不存在稳健因果效应的最有力单一证据。对于 Cutaneotrichosporon 连续丰度（特征 109），能够识别多效工具的估计量均返回以零为中心的估计。污染混合法给出 β = −0.007（SE 0.073；95% 似然区间 −0.080 至 0.065；混合比例 ψ = 0.905）；MR-Lasso 标记出 rs116921468 与驱动变异 rs111394117 两个多效变异，并以其余 20 个工具给出 β = −0.018（SE 0.040；P = 0.66）。加权众数法给出 β = −0.243，bootstrap 标准误宽达 0.121（P = 0.046），不构成稳定确认。保留全部变异的估计量则因驱动变异被保留而仍显著：加权总体最小二乘给出 β = −0.145（SE 0.015），稳健调整轮廓评分给出 β = −0.129（P = 9.8 × 10⁻¹⁰），因此其显著性源于同一单个变异，而非各方法间的共识。

残差阈值轨迹展示了单遍剔除的阈值依赖性。在阈值 2.5 与 3.0 下，驱动变异被剔除，逆方差估计为零（β = −0.015，P = 0.79；β = −0.018，P = 0.66）；而在 3.5 与 4.0 下，因驱动变异残差量级为 3.02 而被保留，估计仍高度显著（β = −0.178，P = 5.7 × 10⁻¹⁷）。在朴素拟合下，最大结局尺度残差属于 rs116921468（|r| = 4.27），驱动变异次之（|r| = 3.02）。因此，主要因果结论建立在不依赖阈值的留一法与区域剔除分析之上——两者独立归零——而非单遍规则。

### 【插入第一阶段/工具强度结果：校准后强度】

原始样本内总 R² 跨特征中位为 5.23%（最高 20.1%），原始联合 F 中位为 23.0，且无特征低于 10；后者是 P < 10⁻⁵ 选择阈值的机械结果，不携带独立信息。经赢家诅咒校准后，总 R² 中位在经验贝叶斯下降至 0.33%、在条件最大似然下降至 0.87%，联合 F 中位分别降至 1.39 与 4.01，且全部 115 个特征均低于弱工具的常规阈值 10。对特征 109，总 R² 由 6.74%（原始）降至两种校准下的 0.43% 与 1.65%，联合 F 由 24.1 降至 1.44 与 5.57。因此原始值被报告为乐观上界，整个工具面板更应定性为弱而非强。

### 【插入结果：跨族群可迁移性】

在 1,953 个两样本均有频率数据的工具中，暴露与结局等位基因频率高度相关（Pearson r = 0.95；Spearman ρ = 0.84；logit 尺度 r = 0.87）。绝对频率差中位为 0.015，第 90 百分位为 0.067，仅 3.7% 的工具差异超过 0.10；无工具在日本样本中单态。低频子集 Pearson 相关较弱（r = 0.44），但绝对差异小（中位 0.010），驱动变异在两群体中均保持多态（汉族频率 0.021；日本 0.063）。因此工具在频率上可迁移，最大相对不确定性局限于低频变异。

### 【插入结果：正交 HLA 对照】

在同一日本平台上，驱动变异 rs111394117 与系统性红斑狼疮呈同方向、名义显著的关联（β = −0.34，SE 0.16，P = 0.034），方向与其类风湿关节炎效应（β = −0.414，P = 5.3 × 10⁻²²）一致。其与 1 型糖尿病、溃疡性结肠炎的关联接近零且不显著（β = −0.042，P = 0.63；β = 0.011，P = 0.95）。与红斑狼疮的一致关联表明，该变异携带跨自身免疫病的 HLA 多效性，而非类风湿关节炎或真菌组特异；在病例数更少的 1 型糖尿病（1,219 例）与溃疡性结肠炎（314 例）队列中的零估计，与功效有限及 HLA 结构差异相符，而非多效性不存在。

## 讨论（修订段落）

### 【修订阳性对照定位】

阳性对照分析应被理解为失败模式的演示，而非对分析流程的验证。在 BMI 对 2 型糖尿病的示例中，朴素逆方差加权因 TCF7L2、GIPR 等血糖直接位点被纳入工具而方向错误（β = −0.288）；单遍残差规则剔除 98 个变异中的 42 个（43%），已超出加权中位数有效性可被假定的比例，且该规则使用了结局侧信息。该示例说明多效位点如何误导朴素估计、残差诊断又如何识别它们，但并不证明该规则无偏，也不证明其能恢复已知效应。

### 【修订局限性】

有三点局限需强调。其一，个体水平检出率、零值比例与丰度分布未公开，故稀疏属的尺度行为只能通过连续与二分类工具的对比来检验；CLR 系数是对数相对丰度的每标准差变化，对少数高观测值仍敏感。其二，五队列固定效应暴露荟萃的分队列汇总统计与队列间异质性（I²）未公开，其中包括两个低于 500 人的队列，因此该异质性无法独立复算。其三，频率一致性支持但不能证明汉族与日本人群间暴露效应量完全相同，且面板校准后的弱工具状态意味着小的因果效应无法被排除。结合反向孟德尔随机化不可行以及 Steiger 结果的尺度依赖性，本研究不对反向因果作任何论断，仅针对真菌组到类风湿关节炎的正向方向。
